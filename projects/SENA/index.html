Concept

Representation

One shared representation of the tissue image, computed once and reused by every output.

Semantic information

What each nucleus is: its type. Capacity for this can be added on its own.

Spatial information

Where each nucleus is and its exact boundary. Capacity for this can be added on its own.

Whole-slide viewer

Reference
Model

Reference layer = pathologist annotation (ground truth). Model layer = nucleus-level predictions of the selected mode (centroid, type, contour), precomputed offline; nothing is computed in the browser. Model modes are disabled when no precomputed output is available for the slide.
