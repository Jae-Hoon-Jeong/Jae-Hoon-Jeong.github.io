One model detects, classifies and outlines every nucleus in a whole-slide image. Semantic capacity (what each nucleus is) and spatial capacity (its exact shape) can each be added on demand, giving four modes: Eff, Cls, Seg and Full. Explore them on real PAIP2020 slides below, and route semantic capacity to selected patches only.

Not for clinical or diagnostic use.

Interactive semantic routing Spend semantic capacity only where it matters.

Move the slider and watch the viewer above: patches are upgraded from Eff to Cls in the order of a label-free router (prediction entropy). Nuclei and contours stay as in Eff; only the class colour changes in routed patches. 0% = Eff, 100% = Cls on every patch.

Why does this work?

One representation

The tissue image is encoded once; every output reads from the same shared representation.

Semantics on demand

Nucleus type benefits from richer semantic features. They are added at inference, by the same trained model, only where requested.

Shape on demand

Exact boundaries come from a separate local refiner, added only when contours matter.
